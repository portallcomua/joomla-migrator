# Joomla Migrator

Поточна версія аналізує старий сайт, переносить частину основних даних ядра та може копіювати папку `images`, якщо обидва сайти доступні з одного файлового сервера. Це рання версія: власні поля, сторонні розширення й перенаправлення URL ще не імпортуються.

## Поточні можливості

- Підключення до MySQL-бази старого сайту з обліковими даними лише для читання
- Автовизначення Joomla 2.5–6.x з `manifest_cache` бази або локального `joomla.xml`
- Ручний вибір сімейства 2.5/3.x/4.x/5.x/6.x, якщо автоматичні джерела недоступні
- Підрахунок записів у відомих таблицях і перелік встановлених розширень
- Попереднє позначення розширень, для яких потрібні окремі адаптери
- Копіювання файлів зі старої папки `images` зі збереженням відносних шляхів
- Перенесення категорій, матеріалів, користувачів, груп користувачів і зв’язків із групами
- Перенесення типів меню, пунктів меню, власних HTML-модулів і їхніх призначень
- Збереження аліасів і спільних метаданих, переприв’язка авторів і категорій через таблицю відповідностей ID
- Повторний запуск без повторного створення вже імпортованих записів

Для локальної структури `old/` і `old/new/` шлях до старого сайту від кореня нового зазвичай `..`. Копіюються тільки файли `images`; відмінні файли в цілі не перезаписуються, а конфлікти виводяться у звіті. Символьні посилання пропускаються.

Версія Joomla може залишитися невизначеною, якщо метадані `com_admin` відсутні або пошкоджені. Пункти головної сторінки після імпорту треба призначити вручну. Власні поля, сторонні розширення й перенаправлення URL ще не імпортуються. Парольні хеші переносяться без перетворення; сумісність застарілих алгоритмів входу потребує окремої перевірки.

## Вимоги

- Joomla з адміністративним інтерфейсом, у якому встановлено компонент
- PHP з розширенням PDO MySQL
- Доступність старої MySQL-бази з сервера нового сайту
- Користувач БД зі схваленими правами лише для читання
- Для копіювання медіа: PHP має мати доступ до старої та нової папок сайту, а в старого сайту мають бути папки `configuration.php` і `images`

## Встановлення компонента

1. Завантажте ZIP-архів компонента
2. У адмін-панелі Joomla: Система → Встановлення → Розширення
3. Завантажте ZIP-файл

## Збірка з вихідного коду

Вміст папки `com_migrator/` необхідно заархівувати в ZIP так, щоб `migrator.xml` був у корені архіву.
